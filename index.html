ייבוא אנשי קשר

הקובץ מוכן לייבוא ולשמירה במכשיר.
  1. לחצו על הכפתור הירוק כדי להתחיל בייבוא קובץ אנשי הקשר.
  2. ב-iPhone: אם הקובץ נפתח בתצוגה מקדימה, לחצו על כפתור שיתוף / Share בפינה הימנית התחתונה.
  3. לאחר מכן בחרו אנשי קשר / Contacts או אפשרות של הוספה לאנשי קשר / Add to Contacts / Create New Contacts, לפי מה שמופיע במכשיר.
  4. אם הקובץ ירד למכשיר ולא נפתח מיד, אפשר לפתוח אותו מתוך קבצים / Files או מתוך הורדות / Downloads.
  5. באנדרואיד: פתחו את קובץ ה-VCF דרך אנשי קשר / Contacts או דרך הקבצים / Files, ואז בחרו באפשרות של ייבוא אנשי קשר.
