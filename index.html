ייבוא אנשי קשר

הקובץ מוכן. הורידו אותו ופעלו לפי ההוראות המתאימות למכשיר שלכם.

📱 iPhone / iPad

  1. לחצו על הורדת קובץ VCF ושמרו או הורידו את הקובץ אל קבצים / Files. בדרך כלל הוא יופיע בתיקיית הורדות / Downloads.
  2. פתחו את אפליקציית קבצים / Files ולחצו על קובץ ה-VCF שהורדתם.
  3. בתצוגת הקובץ לחצו על כפתור שיתוף / Share.
  4. בחרו אנשי קשר / Contacts, ולאחר מכן בחרו באפשרות להוסיף או לייבא את כל אנשי הקשר שמופיעים בקובץ.
אם הקובץ נפתח מיד לאחר ההורדה, אין צורך להיכנס שוב ל-Files — אפשר ללחוץ ישירות על Share ולהמשיך משם.

🤖 Android

  1. לחצו על הורדת קובץ VCF.
  2. פתחו את הקובץ מתוך הודעת ההורדה או מתוך קבצים / Files → הורדות / Downloads.
  3. בחרו לפתוח את הקובץ באמצעות אפליקציית אנשי קשר / Contacts.
  4. אשרו את ייבוא אנשי הקשר ובחרו את החשבון שאליו תרצו לשמור אותם, אם המכשיר מבקש זאת.
